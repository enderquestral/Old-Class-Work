# Old Class Work

A collection of projects, assignments, and experiments from my undergraduate years at Reed College (roughly 2017-2021). This folder keeps old coursework in one place so I do not have to maintain a separate repository for every class, homework set, or one-off project.

The material here is mostly archival/reference work: some assignments are polished, some are rough drafts, and a few were written as learning exercises rather than final products. It is organized primarily by course number, with a few standalone projects that did not fit neatly into a single class folder.

## Repository structure

- [Reed-CSCI121](./Reed-CSCI121): early programming coursework and homework in Python.
- [Reed-CSCI221](./Reed-CSCI221): C++ and assembly work, including algorithms, trees, graph problems, and optimization exercises.
- [Reed-CSCI378](./Reed-CSCI378): deep learning work and coursework in PyTorch, including model explorations and class materials.
- [Reed-CSCI382](./Reed-CSCI382): algorithms/data structures projects and assignments.
- [Reed-CSCI389](./Reed-CSCI389): systems and performance-oriented assignments focused on benchmarking, cache behavior, networking, and optimization.
- [OS-Simplifind](./OS-Simplifind): a simplified UNIX `find` implementation in C++.
- [OSTEP-MapReduce-Project](./OSTEP-MapReduce-Project): a thread-based MapReduce framework built as a concurrency project.

## Notable areas

### Reed-CSCI121
This folder contains early CS coursework and practice exercises, mostly centered on introductory problem-solving and programming fundamentals.

### Reed-CSCI221
This is the largest collection in the archive and includes a mix of:
- C++ assignments and labs
- assembly-language work
- graph and tree algorithms
- TSP and shortest-path tasks
- Huffman coding and related compression-style exercises

### Reed-CSCI378
This directory reflects my deep learning coursework, including the class setup materials, code notebooks, and model-related experiments. It is a good snapshot of early ML/DL work in Python and PyTorch.

### Reed-CSCI382
This folder contains algorithmic and data-structure style work, including exercises in tree balancing, graph algorithms, and other classic CS topics.

### Reed-CSCI389
This section is focused on systems performance and computer architecture concepts. It includes benchmarking, optimization analysis, cache testing, networking, and micro-optimization experiments.

### Standalone projects
Two projects sit outside the course folders:
- [OS-Simplifind](./OS-Simplifind): a C++ implementation modeled on `find` with filtering and execution semantics.
- [OSTEP-MapReduce-Project](./OSTEP-MapReduce-Project): a concurrency-heavy assignment implementing a simplified MapReduce framework.

## Notes

- This archive is primarily for personal reference and historical record.
- Many folders contain old code, comments, and rough notes from the time they were written.
- Some projects have their own local README files and test scripts; those should be treated as the authoritative documentation for each assignment.
- Several course folders also contain older ZIP archives and backup copies, retained as a record of the original materials.

## Intended use

This repo is best used as an archive of past coursework and experimentation rather than a polished, production-ready codebase. If you are looking for a specific class, assignment, or project, the course-numbered folders are the best place to start.
